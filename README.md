# Навігація без GPS

Офлайн-навігатор для України, якому **не потрібні GPS і інтернет**. Він прокладає маршрут по
дорожньому графу з OpenStreetMap і веде водія голосом **крок за кроком**: наступну
підказку озвучує лише тоді, коли водій підтвердить, що виконав попередню.

## Як це працює

Застосунок не знає, де саме авто, тож кожна підказка спирається на орієнтири, які водій
бачить сам:

> «Рушайте по вулиці Січових Стрільців на північ, у бік проспекту Незалежності.
> Через 250 метрів, на найближчому перехресті, поверніть праворуч на проспект Незалежності.»
>
> **[✓ Виконано]**
>
> «Через 600 метрів в'їдьте на кільце та оберіть другий з'їзд на проспект Незалежності.»
>
> **[✓ Виконано]**
>
> «Через 850 метрів, на четвертому перехресті, поверніть ліворуч на вулицю Київську.»

- **Порядковий номер перехрестя** («на третьому перехресті») і відстань до нього. Внутрішньодворові
  проїзди не враховуються.
- **Напрямок на старті**: сторона світу та найближча поперечна вулиця («у бік вулиці Соборної»).
- **Кільця**: номер з'їзду.
- **Розвилки**: «тримайтеся ліворуч / праворуч».
- **Перелік поперечних вулиць на екрані**, щоб пасажир міг стежити за ходом.
- **Два маневри поспіль**: якщо наступний зовсім близько, додається «Одразу після цього…».
- **Назви вулиць у правильних відмінках**: «на вулицю Соборну», «по провулку Тихому»,
  «у бік вулиці Садової».

### Керування в дорозі

| Дія | Як викликати |
|---|---|
| ✓ Виконано (наступний крок) | велика кнопка · пробіл/Enter · «наступний трек» на гарнітурі/кермі · голосом «готово» |
| 🔁 Повторити | кнопка · R · «пауза/відтворення» · «повтори» |
| ◀ Назад | кнопка · Backspace · «попередній трек» · «назад» |
| ↷ Проґавив поворот | застосунок вважає, що ви поїхали прямо до наступного перехрестя (або лишилися на кільці), і перебудовує маршрут без розвороту |
| 📍 Я в іншому місці | торкніться карти там, де ви зараз, і маршрут перебудується |

Кнопки гарнітури та голосові команди вмикаються в ⚙ налаштуваннях. Голосові команди
браузер часто розпізнає лише з інтернетом, тому це додаткова, а не основна можливість.
На час навігації екран не гасне (Wake Lock). Незавершена поїздка зберігається, тож після
перезапуску її можна продовжити.

### Вибір точок без GPS

Початкова точка — це перехрестя, на якому ви стоїте. Оберіть вулицю (працює пошук), потім
поперечну вулицю зі списку. Або натисніть «📍 На карті» і торкніться карти. Карту малюємо
прямо з дорожнього графа, тому тайли не потрібні і все працює офлайн.

## Запуск

```bash
python3 -m http.server 8080     # або: npm run serve
# відкрити http://localhost:8080
```

Це PWA: після першого відкриття (потрібен HTTPS або localhost) її можна «Додати на головний
екран», і далі вона працює без інтернету. Для озвучування потрібен український голос у
системі. На Android: Налаштування → Мова → Синтез мовлення → Google → встановити «Українська».

За замовчуванням відкривається вигадане **Демо-місто** (`data/demo.json`) з односторонніми
вулицями, кільцем і заміською дорогою.

## Карти з OpenStreetMap

`tools/build_graph.py` (лише стандартна бібліотека Python) перетворює OSM у компактний JSON:
фільтрує дороги для авто, враховує односторонній рух і кільця, бере `name:uk`, спрощує
геометрію, але зберігає перехрестя, і лишає найбільшу зв'язну частину мережі.

```bash
# невелика область напряму з Overpass API (south,west,north,east)
python3 tools/build_graph.py --overpass 50.43,30.49,50.46,30.54 -o data/kyiv-center.json --name "Київ, центр"

# місто чи область з дампу Geofabrik (потрібен osmium-tool)
osmium extract -b 30.2,50.2,30.9,50.6 ukraine-latest.osm.pbf -o kyiv.osm.pbf
osmium tags-filter kyiv.osm.pbf w/highway -o kyiv-roads.osm
python3 tools/build_graph.py kyiv-roads.osm -o kyiv.json --name "Київ"
```

Готовий файл відкрийте в застосунку: ⚙ → «Карта». Він зберігається в IndexedDB і далі
доступний офлайн.

## Структура

```
index.html, style.css, sw.js, manifest.webmanifest   — PWA-оболонка
src/router.js        — граф доріг, A* з урахуванням одностороннього руху та штрафів за повороти
src/instructions.js  — генерація українських підказок (перехрестя, кільця, відмінки)
src/session.js       — стан покрокової навігації: виконано / назад / проґавив / перебудова
src/mapview.js       — векторна карта на canvas (pan/zoom/tap)
src/speech.js        — синтез мовлення, голосові команди, кнопки гарнітури
src/storage.js       — IndexedDB для карт, localStorage для поїздки
tools/build_graph.py — OSM → граф;  tools/make_demo.py — демо-місто
tests/               — тести (npm test)
```

## Тести

```bash
npm test   # node --test + python unittest
```

## Обмеження та ідеї на майбутнє

- Повна Україна в одному файлі завелика для браузера, тому краще готувати карту міста або
  області. Далі можна зробити тайловий граф із підвантаженням частин.
- Двосмугові дороги з розділювачем в OSM складаються з двох ліній, тому лічильник перехресть
  може бути неточним. Варто об'єднувати такі вузли під час підготовки карти.
- Пошук за адресою (номер будинку) і POI (АЗС, лікарні, блокпости).
- Оцінка пройденої відстані за часом і швидкістю або через одометр OBD-II, щоб нагадувати
  про поворот завчасно.
- Нативний застосунок (Kotlin / React Native) з офлайн-TTS і кнопками керма без
  «тихого» аудіо.
